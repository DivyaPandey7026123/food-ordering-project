# 🍔 Food Ordering System

## 📖 About

This is a full-stack Food Ordering web application built using the MERN Stack.

Users can:
- Create an account
- Login securely
- Browse food items
- Add items to the cart
- Place orders using Razorpay
- View their orders

## ✨ Features

- User Authentication (JWT)
- Food Menu
- Shopping Cart
- Razorpay Payment Gateway
- Responsive UI
- REST API Integration
